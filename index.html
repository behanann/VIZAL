the idea

Don't just run it.
See the thinking.

Algorithms are sequences of tiny decisions. VIZAL turns those decisions into motion: comparisons light up, values move, nodes get visited, and paths reveal themselves.

  • ✓ User-defined values
  • ✓ Play / reset controls
  • ✓ Adjustable animation speed
  • ✓ Interactive edits and exploration
